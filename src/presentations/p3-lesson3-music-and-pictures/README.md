# P3 第三課《音樂與畫面》— 本機備課版

## 狀態
22頁，按使用者確認的70分鐘督導課設計。課本p.16三圖及p.17作品已核對並加入。
**本版仍缺指定音樂／天鵝影片、本人照片生成的六圖、考試複習材料及第三課最終教案；不是可直接帶進課堂的素材完整版本。** 不提供虛構音訊或假人物。

## 獨立版啟動
保持整個資料夾完整。在此資料夾開Terminal，執行：
`python3 -m http.server 8745 --bind 127.0.0.1`
在Chrome開 `http://127.0.0.1:8745/`。如8745已被佔用可改其他port。
左右鍵／上一頁下一頁切頁；下拉選單直接跳頁／組別；全螢幕按鈕；「教師備註」預設收起。
不要只複製index.html。Music Maker的css/js/vendor/media全部保留。

## 接入既有系統
已在本機專案新增 `src/presentations/p3-lesson3-music-and-pictures/`，registry會自動列出。
啟動命令：在現有專案用 `pnpm dev`；建置 `pnpm build:pages`。
此工作未commit、push或公開部署。避免未確認的課本圖像／媒體被直接放上公開網站。

## 補入素材
六張圖片放入images資料夾：G1_Rain.png、G2_Running.png、G3_Sea.png、G4_Wind.png、Demo_Station.png、Exit_Kite.png。
這些須以本人照片生成，目前只有位置，沒有用隨機人像替代。
將合法音樂及影片放入audio、video，再改獨立版 `config.js` 對應src；例如 `audio/Chopin_Op64_No1.mp3`。
現有系統版請改 `src/presentations/p3-lesson3-music-and-pictures/media-config.json`，媒體放到 `public/media/p3-lesson3/`。
未補檔前src維持空字串；按播放會說明待補，不播放其他歌曲。
起點start以秒計，duration預設30秒，按最終教案改為20–40秒的合適片段。
三個天鵝狀態共用同一影片、起點、長度；影片原聲永遠靜音，有音樂狀態只播放對應配樂。

## Music Maker雙視窗
獨立版已附完整既有App原檔，沒有改寫引擎。預設入口music-maker/index.html。
在同一電腦開另一視窗；投影持續顯示簡報圖片，教師在未投影的延伸桌面操作App。若電腦只能鏡像單一畫面，切換App時圖片會暫時被取代：先調好設定，再返回圖片及播放背景，必須在實機確認，不宣稱已可靠同頁嵌入。
返回原簡報分頁會保留目前組別頁。Music Maker播放前須在App按Start解鎖音訊，結束試演先在App停止音樂再切組；簡報無權控制另一視窗的App播放。
整合版可在「Music Maker教師設定」填入網址，投影電腦亦須設定。這是本機設定，不跨裝置自動同步。
實際選項：速度慢／中／快；樂器鋼琴／鼓／弦樂／電子琴／鈴鐘；心情及風格卡片存在，但部分卡片改變多項音樂設定。沒有獨立力度滑桿。音色是合成聲，不是真實樂器錄音。

## 教學及來源
學生不登入、不操作裝置；個人先想，再用紙本圈選及口頭解釋。
App負責背景氣氛；學生選一種熟悉的身體聲響突出細節，看教師手勢加入／停止，不要求固定四拍或逐拍同步。
來源及權利狀態見assets_manifest.md；教材照片只隨本機備課包使用，未核實公開再散布權。
SOW為每循環兩節平均35分鐘，本文件按使用者最新確認的完整70分鐘安排；沒有把科技使用聲稱為評級保證。

## 驗證與限制
應檢查1366×768及1920×1080版面、22頁前後及直接跳頁、備註隱藏、全螢幕、缺媒體提示、App入口。
在Chrome尚未做實機音訊／影片播放測試（素材缺失），Safari及實體iPad尚未驗證。
配置合法音樂後，須實測播放、重播、停止、切頁暫停，及音訊解鎖；不要把UI可用當作已驗證聲音。

詳細實際檢查結果見 VALIDATION.md。內置瀏覽器兩種尺寸的22頁已逐頁檢查，缺檔提示、備註及App入口已查看；不是Chrome／Safari播放驗證。
